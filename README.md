# Gym Tracker

A React + Vite starter app for tracking workouts.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Project structure

- `src/main.tsx` — application entrypoint
- `src/App.tsx` — main page component
- `src/components/WorkoutList.tsx` — workout list UI
- `src/types.ts` — shared workout types
- `vite.config.ts` — Vite configuration
